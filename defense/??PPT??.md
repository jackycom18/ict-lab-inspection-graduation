# 答辩 PPT 大纲

## 第 1 页：题目与个人信息

- 校园实验室设备巡检与故障工单系统的设计与实现
- 学生、学院、指导教师、日期由本人填写

## 第 2 页：研究背景

- 实验室设备分散、巡检周期不统一
- 纸质记录难检索，即时通信工单难追踪
- 目标是形成设备、巡检和维修的闭环

## 第 3 页：需求分析

- 三类角色：管理员、巡检员、维修人员
- 四项核心业务：设备、巡检、工单、统计
- 八项功能需求和六项非功能需求

## 第 4 页：系统架构

- 浏览器工作台
- Node.js REST API
- JSON 文件持久化
- 零第三方运行时依赖

## 第 5 页：数据与状态机

- 设备、巡检、工单三个实体
- 工单严格按五状态单向前进
- 非法跳级返回 HTTP 409

## 第 6 页：系统演示

- 设备阵列与状态指标
- 设备登记和巡检提交
- 创建工单并推进维修状态

## 第 7 页：测试结果

- 5 项自动化 API 测试全部通过
- 浏览器端新增设备和工单验证通过
- 桌面与移动视口均无横向溢出

## 第 8 页：总结与展望

- 完成实验室设备管理闭环
- 验证 AgentTeam 多角色协作流程
- 后续接入认证、二维码、数据库和故障预测
