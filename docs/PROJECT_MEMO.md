# 项目：校园实验室设备巡检与故障工单系统

> 最后更新：2026-10-27

## 项目总览

- 目标：完成 ICT 1.12 AgentTeam 毕业设计全流程作品。
- 技术栈：Node.js 内置 HTTP、HTML/CSS/JavaScript、JSON 文件、node:test。
- 运行：`npm start`
- 测试：`npm test`
- 入口：`backend/server.mjs`、`frontend/index.html`

## 环境配置

- 系统：Windows 11
- Node.js：v24.18.1
- 依赖：无第三方运行时依赖
- 数据：首次启动生成 `data/lab-db.json`
- 浏览器验收：Microsoft Edge 无头模式
