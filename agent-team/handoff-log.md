# AgentTeam 阶段交接记录

| 阶段 | 角色 | 输入 | 交付物 | 状态 |
|---|---|---|---|---|
| 1 需求 | 需求分析师 | 选题、用户角色、业务目标 | 需求规格、用例图、追踪矩阵 | 完成 |
| 2 设计 | 系统架构师 | 已确认需求 | 架构图、ER 图、API 契约、DDL | 完成 |
| 3 开发-前端 | 前端开发者 | API 契约、视觉方向 | 仪表台式单页工作台 | 完成 |
| 3 开发-后端 | 后端开发者 | API 契约、状态机 | JSON 存储、REST API、输入校验 | 完成 |
| 4 测试 | 测试工程师 | 需求追踪矩阵、前后端代码 | API 自动化测试、测试报告 | 完成 |
| 4 论文 | 论文撰写者 | 全阶段产物与测试结果 | 六章毕业论文 | 完成 |
| 5 答辩 | 答辩助手 | 系统演示、测试结果、论文 | PPT 大纲、演示脚本、预测 Q&A | 完成 |

## 交接规则

1. 下游角色只读取已经提交的上游产物。
2. 测试发现问题时，由对应开发角色修复，测试角色重新执行。
3. 论文不得虚构性能、用户量或调研样本。
4. 答辩助手只使用已实现功能和已通过测试作为证据。
